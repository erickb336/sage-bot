Who refuses what in a lead session

Four layers limit a session, and Erick decides what none of them may do. Only the sandbox guarantees a file or network boundary (standing order 14); the hook is a second layer. The lead sees each refusal the same way: one short line in the thread, with the layer's name (moment 3).
