A sage-lead talks to sage from Discord

Task T72 · run R369 · design branch design/t72-full · builds on the T69 page (design/t69) · nothing is built

What this is. A clickable design of two decisions by Erick. G22, "Full access, with guardrails": a sage-lead talks to sage in Discord as if from Erick's terminal, to frame tasks, ask for reviews and ask for status. And the scope addition of 5 Oct: sage-bot works in any channel it is added to, and every @sage-bot mention opens a thread. Four guardrails hold, and each has its own moment below.

  1. Erick still approves anything irreversible: the automatic-merge mode, deleting data, secrets, deploys, merges and force-pushes. A lead never switches the mode. (Moment 3)
  2. Text from a sage-apprentice reaches sage only as quoted data, never as instructions. (Moment 4)
  3. sage-bot logs every lead message, and Erick can read the log. (Moment 6)
  4. A kill switch cuts the link from Discord to sage. (Moment 7)

Where it fits. T69 designed fixed commands in one #ask-sage channel and kept Discord text out of the live session. G22 and the scope addition replace both. Merged since: read commands (T71) and the leads-only card for automatic merge (T73). Being built: every reply is public, and sage-bot ignores members with no sage role (T95, G20). Options I rejected, and why

A private #sage-leads channel for talksIt hides the talk from apprentices, so they learn nothing, against G20. Erick's thread model already keeps talks apart.
Answers in place when sage-bot lacks thread rightsIt breaks the rule that every request lives in a thread, and the channel fills. sage-bot asks for the right instead (moment 1).
A model decides what is irreversibleA list of actions in sage-bot and sage's own permission rules is exact. A model can be talked out of a refusal. The list is the guardrail; sage's words only explain it.
Drop apprentice text instead of quoting itG22 says it reaches sage as quoted data. Dropping it also loses useful notes, for example "the test fails on my machine too".
The log only as a Discord channelDiscord is not Erick's machine, and a channel can be edited by a server admin. The PE's shape keeps the append-only file on the Mac as the record; #sage-audit is a copy to read.
A project per thread, asked at every mentionOne more question at each request. A channel's project, set once, answers it (Q1).
